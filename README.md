# Swit Distro: release-uri

Aici stau doar fișierele publicate pentru sistemele instalate:

- `modules-latest`: actualizările modulelor Swit Distro (`manifest.json` semnat + arhivele);
- `catalog-latest`: catalogul Centrului de aplicații (`catalog.json` semnat + iconițele). AppImage-urile se descarcă de la sursele oficiale ale proiectelor.

Totul e semnat ed25519; cheia publică e în sistem, în `/etc/desktop/update-key.pem`.
